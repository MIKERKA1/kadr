# КАДР · компьютерный клуб 24/7

Демонстрационный сайт вымышленного компьютерного клуба для портфолио. Клуб, адрес, телефон, цены и характеристики придуманы.

Идея: «кадр» означает и название клуба, и единицу того, что показывает монитор на 540 Гц. Через всю страницу проходит рамка видоискателя. Внутри неё меняются зоны клуба, рамка наводится на детали железа, в ней же переключаются услуги.

## Запуск

```bash
npm install
npm run dev        # http://localhost:4410
npm run build      # сборка в dist/
npm run preview    # http://localhost:4411, отдаёт dist/
```

## Проверки

```bash
npm test           # юнит-тесты цен (node --test, 7 проверок)
npm run e2e        # Playwright, десктоп 1440 и Pixel 7 (нужен `npx playwright install chromium`)
```

## Устройство

| Файл | Что делает |
| --- | --- |
| `index.html` | Вся разметка и весь текст страницы |
| `src/pricing.ts` | Единственный источник цен: тарифы, пакеты, расчёт, подсказка по размеру компании |
| `src/hero.ts` | Интро первого экрана (anime.js): буквы с вариативной шириной, шторка кадра, счётчик 60→540, смена фото, наклон за курсором и уход при прокрутке (Motion) |
| `src/hz.ts` | Сравнение 60 Гц и выбранной частоты на canvas, замер частоты экрана посетителя |
| `src/sections.ts` | Навигация, меню, появления секций, закреплённый показ зон, хотспоты железа, «Кроме игр», глаголы первого визита, лента, CTA |
| `src/calc.ts` | Калькулятор, таблица цен, блок «Сколько вас придёт», форма брони |
| `scripts/photos.py` | Приводит найденные фото к одному грейду и режет WebP 800/1600 |

Разделение библиотек: anime.js отвечает за таймлайны и разбивку текста на буквы, Motion за всё, что привязано к прокрутке, пружины и `inView`. При `prefers-reduced-motion` интро, смена фото, параллакс и видео отключаются, контент виден сразу.

## Что демонстрационное

- Бронь никуда не отправляется. После проверки форма показывает, что получил бы администратор, и прямо пишет, что бронь не отправлена.
- Нет реальной загрузки зала. Единственное живое значение на странице: частота экрана посетителя, она замеряется в его браузере.
- Телефон `+7 (000) …` не выдан ни одному оператору, домен `.example` зарезервирован, Плёночного проезда в Москве нет.

## Фото и видео

Все снимки взяты из Wikimedia Commons, их список с лицензиями есть в подвале сайта и в `src/assets/raw/credits.json`. На фото другие клубы и события, сайт подписывает их как иллюстративные. Обработанные версии снимков под CC BY-SA распространяются под той же лицензией. Перед запуском настоящего клуба их нужно заменить своими.
